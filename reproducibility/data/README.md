# Data

## `raw/` (immutable inputs to analysis)
- `rollout_ledger.csv` — canonical append-only ledger, one row per evaluation rollout (3000 controller
  rows: H0/H1/H2 × 1000). Regenerated by `scripts/build_ledger.py` from the immutable source
  `results/rigorous/canonical/episode_audit.csv` (in the parent research repo). The non-canonical smoke
  run `H0_A2C_map-random-01_seed101_steps64` is excluded.
- `rollout_ledger.schema.json` — field definitions and the `success+collision+timeout==1` invariant.
- `manuscript_claims.csv` — every audited manuscript number with recompute key and tolerance.
- `trajectories/` — per-episode `.npz` are **not redistributed by default** (4000 files). They live in the
  research repo under `results/rigorous/artifacts/<run_id>/trajectories/` and are checksummed in each unit's
  `SHA256SUMS`. See `manifests/raw_artifacts.csv`.

## `derived/` (regenerated; never hand-edited)
- `controller_summary.csv`, `map_controller_summary.csv`, `map_training_run_summary.csv` — from `analysis/01`.
- `paired_h0_h1_differences.csv`, `statistical_results.csv` — from `analysis/02`.
- `evaluation_seed_slots.csv` — 50 slots per unit with duplicate flags, from `scripts/validate_ledger.py`.

## `external/`
Empty. No third-party datasets are used.

## Provenance
Every derived file is reproducible with one command from `raw/rollout_ledger.csv`. Do not edit derived files;
rerun `scripts/reproduce_analysis.py`.
